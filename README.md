# Shell, permisos

Proyecto de la Universidad Tecnológica (UTEC) sobre shell scripting y permisos en Linux.

## Descripción

Cada script cumple con:
- Ejecutable en Ubuntu 22.04 LTS
- Primera línea: `#!/bin/bash`
- Exactamente 2 líneas por archivo
- Termina en nueva línea
- Sin comillas invertidas, `&&`, `||` ni `;`

## Scripts

### `permissions/0-iam_betty`
Cambia el usuario actual al usuario `betty` mediante el comando `su betty`.
